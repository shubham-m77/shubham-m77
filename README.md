### 🛒 Instokk — Full-Stack Quick-Commerce Platform

End-to-end order pipeline covering products, categories, cart, checkout, and payments — architected as 15+ modular REST API resources with matching MongoDB schemas.

**Highlights**
- Centralized client-side state and caching across cart, checkout, and session flows using **Zustand**
- Secure dual-mode transactions (COD & UPI) via **Razorpay** webhook processing, price-snapshot logic, and **JWT**-based role authorization
- Production-split architecture — frontend on **Vercel**, backend on **Railway** — deployed as independently scalable services
